# Triage Labels

技能使用的五个角色与 GitHub 标签同名。提到某个角色时，使用本表对应标签。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已形成可供 agent 执行的规格 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予实施 |

标签不替代 issue 正文中的范围、阶段门槛或待决事项。后续若沿用其他标签名称，只修改映射并同步根目录入口说明。
