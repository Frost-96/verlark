# 首版聚焦先听后用的学习流程

用户希望改善想说却说不出、卡词和组织句子的困难，并强调听说结合。2026-10-07，用户选择“先听后用”，接受网站提供经过检查的短对话，听完后表达自己的情况，一次约 5–10 分钟；提供按需帮助、录后重点反馈和再次尝试，不以综合分数或语法完全正确作为完成条件。

相比继续维护写作、独立 AI Coach、自由口语对话等并列入口，首版仅保留登录注册、材料选择、上述听说练习、反馈与练习记录。这便于围绕一个明确的学习流程重新建模与验证，代价是新版首发覆盖的功能少于旧版；原有功能不自动获得重建承诺，也不在本轮删除其代码。

这是范围与交互顺序的选择，尚未证明该流程的学习效果。完成练习不等于掌握表达；后续复习安排、技术栈与音频存储不由本决定隐含确定。
