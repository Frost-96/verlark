# #10 表达反馈与恢复实施记录

日期：2026-10-10。基线：`706bd3615fcf25cafdf26719ca2ab6e48665d4d7`（#9 已合并）。本票仅交付 #10；结束练习、再次作答和历史管理的剩余操作由各自票据交付。

## 交付范围

- `practice.requestFeedback(learner, practiceId, attemptId, confirmationId)` 与 `recoverFeedback(...)` 是业务公开入口。确认文本必须存在且属于该作答；练习所有权和未结束状态在短事务内重新检查。客户端不传入用户标识。
- 新表 `expression_feedback` 每个确认文本版本最多一条结果；组合外键保证确认文本和作答相符，并随练习级联删除。状态、处理权和成功结果具有数据库检查约束。迁移 `0006_third_zodiak.sql` 先建立组合唯一索引，再建立引用它的外键。
- 发起请求先锁练习并保存 60 秒处理权，事务外调用外部 Adapter；写回重新检查记录存续、所有权、未结束状态、token 与期限。成功结果不可覆盖；重试不产生作答，仍固定原确认文本。确认文本在生成途中变化时，结果仅属于原版本，不成为新版本的当前有效反馈。
- 保存规则版本 `expression-v1`、请求标识、生成时间、provider/model。页面展示确切依据文本与版本；当前反馈和历史反馈分别显示。失败/无内容不成为有效反馈；异常与过期恢复显示“结果未知”，不声称远端取消。
- 请求来源、实际会话、JSON 严格结构及 1 KB 请求体上限在 HTTP 边界执行，响应禁止缓存。服务原始错误与未知代理响应不进入界面。
- `DEVELOPMENT_FEEDBACK=true` 必须显式设置，且仅允许 `development`/`test`；配置与 Adapter 双重检查。默认不可用，生产不回退为固定结果。界面明确显示替身及支持样例。
- 浏览器请求最多等待 70 秒，查询或重试前本地中断不被当作远端取消。转写与反馈控件共享快照请求序号，旧查询响应不会覆盖较新的确认/反馈结果。此项通过延迟真实 GET 响应的浏览器回归确认。

## 固定质量样例检查

以下是人工编写并逐条阅读的开发示例，自动测试经 practice 接受后核对数量、引用、中文解释、关键改进及禁用评价。它们不来自真实模型。

| 确认文本 | 预期及检查结论 |
| --- | --- |
| `I will read tomorrow.` | 意思清楚；零纠错、零替代，不为了填充反馈而挑错 |
| `I will read a book this weekend.` | 意思清楚；零纠错。`I'm planning to read a book this weekend.` 单列可选表达，解释明确“原话不是错误” |
| `I borrow you my book tomorrow.` | 一个重点：borrow/lend 的借入、借出方向；建议 `I'll lend you my book tomorrow.`，说明以“如果想借给对方”为条件，不擅自断定意图 |
| `I went tomorrow. I borrow you my book.` | 两个重点：过去与将来的时间冲突、借书方向；分别提供英语建议，未追加不影响理解的风格纠错 |
| 其他未列出的文本 | 开发替身明确失败；不根据任意文本返回固定“表达清楚”假评估 |

实践模块执行严格结构、零至两个问题、英语建议、引用必须来自原确认文本、中文解释，以及对明确发音/评分/掌握等词语的保守守卫。词语守卫只拒绝已知越界说法，可能有误拒或遗漏；不能证明语义判断准确，不能代替真实模型质量验收。没有 score/pronunciation/mastered 等合法字段。
