# #20 v4 有限质量复验方案

2026-10-12。v4 是待验证改进，不是质量通过结论；服务默认禁用。模型仍为 `qwen3.7-flash-2026-07-15`。

## 改进依据

v3 对已给示例表现较好，但新句仍把轻微动词形态问题当作理解问题，也曾将第一人称改为占位符。v4 将示例前的通用判定顺序写清：先按日常交流理解，只有无法确定的关键意思才进入问题；解释应说清听者哪里不能理解；改进仅替换相关片段，保留原文已明确的人物、否定、时间、地点、数量与方向。不新增后处理白名单或把结果强制清空。英文样例只沿用已暴露的回归集，不能算独立保留集。

## 独立复验

由未编写提示的审查者准备新合成样本，冻结后再调用。通过 `FEEDBACK_SAMPLES_FILE` 传入 JSON `[["label", "synthetic English text"], ...]`；不将新保留集写入提示。文件最多30例，单例最多2000字符且标签唯一；这些是脚本输入防护，本轮实际调用数须服从独立批准的更低限制。可继续使用 `FEEDBACK_SAMPLE_FILTER`，未知标签会拒绝运行。保留集至少同时覆盖意思清楚但语法轻微不规范、人物歧义、真正方向／时间冲突与保留第一人称、否定和事实的复合表达，避免只验证空 issues。

必须在查看输出前写下每例允许的问题与禁止的事实改变。人工逐例核查 F01–F03；结构合法、mock 通过、只命中曾暴露案例均不代表语义质量通过。第一轮保留集输出若失败即记录失败；不再把同一组称为未见保留集。不自动重试、不自动切模型；未知结果立即停止并保留预留。

v4 单例预留为 4,427 加该文本 JSON 转义后的 UTF-8 字节数。若20例文本各不超过200个未转义 ASCII 字符，则最大预留92,540 token；有引号、换行或非 ASCII 字符时须按实际 JSON 字节重新计算。实际供应商计量不是上述预留，也不构成零账单证明。沿用原账本，不能清理、换库或回收旧预留来获得额度；根代理核对新批准的累计上限、免费权益与截止时间后执行。

## 离线验证边界

自定义输入已离线验证重复标签、错误形状与未知筛选标签均在创建回执、连接数据库和调用供应商前拒绝。Adapter 原有测试继续只替换外部 transport，使用真实隔离 PostgreSQL schema。离线验证不判断模型语义质量。
