# #13 按当前有效反馈结束练习并保证只读

日期：2026-10-11。实施基线：`0eee38f`；范围为 #13、首版规格 P09–P11、P12 只读、A04、F02。依赖 #11、#12 已关闭，保留 #14 重练和 #15 整次删除。

## 行为与实现

新增 practice 公开操作 `finish(learner, practiceId)` 和 `POST /api/practices/:id/finish`。请求使用真实认证会话，检查同源，接受空对象，不接受客户端身份。没有当前有效反馈时返回 `feedback-required`；任意作答识别或反馈仍处于 processing 时返回 `processing`，包括历史确认文本的处理。只有至少一份当前确认文本的成功反馈且没有处理中请求时才保存结束状态。零纠错项的成功反馈满足条件，其他作答无需全部成功、核对或生成反馈。

结束检查、结束写入、提交作答、识别/反馈登记及结果写回、文本更正共用练习行的 PostgreSQL 事务锁。检查依据已保存的确认文本与反馈，未增加另一份有效性状态。重复结束幂等返回当前记录。已有 `ended_at` 字段足够承载此次变更，因此没有新增迁移。录音文件上传完成后也重新检查结束状态；结束后到达的上传不会返回可提交引用。上传期间已写入的开发文件仍遵守已有整次清理机制，不承诺远端取消或新增保留期限。

已结束时既有变更守卫拒绝追加作答、确认/更正、识别/反馈请求和恢复操作。已接收 submission 的同标识重复请求仍是原结果的恢复读取，不创建新作答。超时请求不会被结束操作偷偷视为完成，必须先通过已有 `recoverRecognition` / `recoverFeedback` 置为 unknown 并撤销本地处理权；迟到结果不能回写。提示明确“本地失效不表示远端已取消”。

中文界面增加结束和查询结束状态。最终条件每次由服务端检查，避免嵌套反馈组件的局部状态导致按钮错误禁用。失败保留编辑与录音草稿；结束成功或查询确认已结束时，以服务端最终详情更新整个练习界面、卸载原录音组件释放麦克风和草稿，不依赖刷新页面或可被取消的 beforeunload 跳转。结束界面显示只读原因及各次作答真实状态；不提供追加、更正、重试入口，不将结束描述为掌握。原版本重练和整次删除保持可用。

## 审查修正：结束后退出待核对提交恢复

规格审查发现：录音上传成功但提交 POST 未送达服务端时，本地保存的 submission 标记仍存在；结束后的 Recording 重新挂载会查不到这次作答，并永久保持 pending。虽然变更控件已隐藏，旧的离页确认仍会阻止从只读页面返回练习记录。

先扩展真实浏览器验收：完成文件上传，拦截并中止提交 POST，再结束、查询结束状态，点击顶部“练习记录”。修复前测试实际失败，URL 保持在原练习；测试捕获并拒绝了不应出现的离页对话框。随后只调整结束状态的入口恢复：最终详情已经包含全部已接收作答，结束后也不会接收新的作答，因此清理该练习的本地恢复标记并跳过恢复查询；存储不可用也不会让只读记录重新成为待提交状态。已接收作答保留在服务端最终详情，不删除或改写历史。

回归还覆盖返回已结束记录、重新加载、再次点击历史链接均无离页确认，没有恢复提交控件，前后服务端作答记录完全一致。因为改动涉及录音组件挂载恢复，本轮除结束场景外，还运行既有录音响应丢失、多页提交和过期恢复响应场景。此前全套 93 个模块测试、28 个浏览器测试和生产构建为审查前记录；本轮没有改动服务端，未重复执行全套模块测试或生产构建。

本轮修正后的验证：`playwright test tests/e2e/finish.spec.ts tests/e2e/recording.spec.ts tests/e2e/recording-recovery.spec.ts` 两视口共 **8/8 通过**；`pnpm typecheck`、`pnpm lint`、`pnpm format:check` 和 `git diff --check` 通过。
