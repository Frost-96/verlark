# 整次删除练习与录音清理（#15）

日期：2026-10-11。实现范围是第二阶段的业务行为及开发 Adapter；真实存储、保留期限与最终删除语义仍未选定。

## 行为与边界

- `practice.delete` 验证可信学习者与所有权，锁定练习行，与提交、识别和反馈变更共用串行化点。删除时级联移除作答、原始转写、确认文本和反馈，迟到处理无法重新挂回。
- 练习表仅保留不可读取的删除标记及原有请求标识等关联元数据，用于阻止原开始请求重放复活记录；公开读取、提交、修改、列表均排除已删记录。没有保留可读取的练习详情或作答。零作答与旧内容版本均支持。
- `readDeletion`、`listDeletions` 与 `retryDeletion` 提供持久化删除凭据和录音清理结果。清理事务外调用文件 Adapter；短事务取得一分钟处理权，结果只有在令牌一致且未过期时才能写回。请求失联后刷新仍能看见处理状态，并在到期后重试。
- 受保护 HTTP 入口仅采用实际会话身份、检查来源并拒绝非空请求体；请求体不能指定他人身份。中文界面提供删除确认、取消、持久化状态与清理重试。
- 录音 Adapter 的 `removePractice` 按学习者与练习范围持久化封闭标记，再清扫文件；重复操作不会重新开放范围。`read`、`inspect` 拒绝已封闭范围。保存前后均核对封闭标记，删除与上传交错时迟到保存会清理自己的文件并拒绝结果。业务层保存返回前再次检查练习状态。
- 文件清理失败不回滚业务删除，显示“练习记录已删除，但录音清理未完成或结果未知”，保留重试动作；成功文案仅为“开发录音清理已执行”。成功后也可再次检查并清扫。

迁移 `0007_practice_deletion.sql` 添加练习删除标记及独立清理记录。未修改材料内容或选择生产文件供应商。

## 明确未验证或延后

- 真实文件服务、供应商取消/删除语义、保留期限、备份清理、生产物理擦除和部署地区均未验收。
- 开发本地文件实现不承诺进程崩溃时同步完成物理擦除：若在发布文件后、保存的二次封闭检查前崩溃，文件可能暂留磁盘，但已封闭范围不能通过 Adapter 读取。再次清理会扫除正式文件及本实现带范围前缀的上传临时文件。界面保留再次检查动作；没有将 Adapter 已执行解释为生产全量擦除证明。更早版本不带范围前缀的孤立临时文件没有追溯清理承诺。
- 没有后台自动调度清理；用户可在删除与录音清理区域恢复失联或失败的请求。过期本地处理权不表示远端请求被取消。
- 本票未单独运行生产构建，集成分支统一执行；不将类型检查或开发浏览器通过等同于真实接入和生产可用。
