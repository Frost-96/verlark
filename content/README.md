# 首份开发材料

`weekend-plans-v1.json` 是 #7 的日常短对话。2026-10-09 检查了英语句子、中文释义、关键词、句式与表达任务的一致性：任务要求学习者表达自己的周末计划，完整示例保持按需显示。内容难度与真实学习效果尚未经过用户试用。

音频使用 macOS Samantha 系统语音，以每分钟 145 词从材料原文生成（仅移除 A/B 说话人标签），WAVE、16-bit、22050Hz。它是可播放的开发素材，不代表最终教学录音或供应商选择。音频与源文件逐行对应；自动浏览器检查验证可加载、播放和重听，最终听辨质量留待真实材料阶段。

先运行 `pnpm db:migrate`，再运行 `pnpm content:publish`。发布命令检查本地音频存在，将全部文本、任务、释义、提示及稳定音频路径写入数据库。页面不会读取此目录。相同材料与版本的相同内容重复发布返回原版本；内容不同则拒绝，必须增加版本号并保留相应音频资源。

历史文字不依赖部署包保留源文件；音频文件需随当前部署保存，最终音频存储与保留规则仍待 #17–#18 确定。维护命令不对学习者开放，不在页面请求中自动发布。
