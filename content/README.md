# 首份开发材料

`weekend-plans-v1.json` 是 #7 的日常短对话。2026-10-09 检查了英语句子、中文释义、关键词、句式与表达任务的一致性：任务要求学习者表达自己的周末计划，完整示例保持按需显示。内容难度与真实学习效果尚未经过用户试用。

音频使用 macOS Samantha 系统语音，以每分钟 145 词从材料原文生成（仅移除 A/B 说话人标签），WAVE、16-bit、22050Hz。它是可播放的开发素材，不代表最终教学录音或供应商选择。音频与源文件逐行对应；自动浏览器检查验证可加载、播放和重听，最终听辨质量留待真实材料阶段。

先运行 `pnpm db:migrate`，再运行 `pnpm content:publish`。发布命令检查本地音频存在，将全部文本、任务、释义、提示及稳定音频路径写入数据库。页面不会读取此目录。相同材料与版本的相同内容重复发布返回原版本；内容不同则拒绝，必须增加版本号并保留相应音频资源。

历史文字不依赖部署包保留源文件；音频文件需随当前部署保存，最终音频存储与保留规则仍待 #17–#18 确定。维护命令不对学习者开放，不在页面请求中自动发布。

## 新版、撤下与历史重练

内容版本包含文本、音频引用、表达任务、释义与提示。先检查整份新材料及音频，再使用新的 `revision` 发布：

```sh
pnpm content:publish content/weekend-plans-v2.json
```

发布输出包含内容版本 UUID。发布新版不会撤下旧版；目录选取当前最高的可用版本，历史重练仍使用原可用版本，且创建独立练习。相同材料与版本号只能重复发布完全相同的内容，不能覆盖旧版。

需要停止使用某版本时，明确提供该版本 UUID：

```sh
pnpm content:withdraw <内容版本UUID>
```

撤下是幂等维护操作，没有面向学习者的管理后台或维护 HTTP 入口。它保留数据库中的历史文字、任务、释义和提示，但禁止使用该版本开始或重练；目录将选择仍可用的最高版本，没有可用版本时不显示该材料。撤下不会自动将历史重练替换为新版，再次发布相同源文件也不会恢复已撤下版本；修订应增加版本号。

练习创建与撤下在 PostgreSQL 中以内容版本行锁协调：已取得可用版本的创建先提交，撤下随后生效；撤下后取得锁的新创建被拒绝。旧源文件从部署包移除不影响数据库历史文字，音频文件可用性、保留和清理仍须按最终存储方案单独验收，不能据此删除旧音频。
